# MUTINY — BLACK BOX INDUSTRIAL

MUTINY should be identifiable without its logo. The visual language is **BLACK BOX INDUSTRIAL**: classified naval documentation, cassette-era spacecraft instrumentation, archival typography, and a ship interface that degrades with the vessel.

## Rules

- **Void / Carbon** form the world. Warm bone is the primary reading color.
- **Oxide red** means danger, sabotage, ejection, or irreversible action.
- **Instrument amber** means telemetry, uncertainty, power, and system state.
- **Utility green** is rare and reserved for verified/stable states.
- Editorial serif is for narrative, role identity, and major emotional beats.
- Monospace is for machine state, telemetry, labels, and protocol.
- Motion must feel mechanical: slide, scan, seal, shutter, stamp, pulse. Never bounce.
- Avoid cards whenever information can belong to a manifest, dossier, console, strip, schematic, or archive.
- Wallet/chain controls belong in the world as operational controls, never as generic Web3 chrome.

## Primary experiences

1. **Uplink** — cinematic system boot followed by the `EVERYONE HAS SOMETHING TO HIDE.` composition.
2. **Manifest** — crew intake as a sealed personnel table.
3. **Dossier** — private role reveal on warm archival paper; the file is burned before play.
4. **Bridge** — vessel schematic at center, crew manifest at left, private/public intelligence at right, confidential controls below.
5. **Failure states** — the whole interface destabilizes as minimum public ship integrity crosses 40% and 20%.
6. **BLACK BOX** — the UI leaves the dark ship world and enters a warm archival declassification mode that exposes true vs displayed state, roles, orders, effects, and ballots.
7. **Archive** — protocol documentation is treated like a declassified operations manual, not a generic docs page.

## Signature moment

The player sees a crew member claim `REACTOR +3`. BLACK BOX later prints `ACTUAL EFFECT -3`, beside the true system integrity and any poisoned public telemetry. The interface must make that discrepancy impossible to miss.
